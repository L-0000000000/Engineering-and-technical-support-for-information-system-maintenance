1.Указать не менее 10 базовых команд Git и краткое описание.

Создание:
git init - создает новый репозиторий.
git clone <ссылка> - копирует готовый проект.

Проверка:
git status - показывает текущее состояние.
git add <файл> - добавляет файлы в корзину для сохранения.

Коммиты:
git commit -m "сообщение" - делает снимок (сохранение) проекта.
git log - показывает историю сохранений.

Работа с GitHub:
git push - отправляет изменения в интернет.
git pull - забирает изменения из интернета.

Эксперименты:
git branch <название> - создает новую ветку.
git checkout <название> - переключает тебя между ветками.
